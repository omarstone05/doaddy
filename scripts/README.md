# Scripts Directory

This directory contains utility scripts, test scripts, and debug scripts for the Addy2.0 project.

## Scripts

### Test Scripts
- `test-twilio-quick.php` - Quick test for Twilio WhatsApp integration
- `test-twilio-whatsapp.php` - Full Twilio WhatsApp test
- `debug_sale.php` - Debug script for retail sales functionality

### Utility Scripts
- `upload-images.php` - Image upload utility
- `add-phone-to-user.php` - Utility to add phone numbers to users
- `quick-login.php` - Quick login utility script
- `create_multi_tenancy_structure.php` - Multi-tenancy structure creation script

## Usage

These scripts are typically run from the command line:

```bash
php scripts/script-name.php
```

**Note**: Some scripts may require Laravel to be bootstrapped. Ensure you're running them from the project root directory.
